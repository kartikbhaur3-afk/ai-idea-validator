# AI Idea Validator

An AI-powered startup concept and market demand validator built for the Next Founders Hackathon. 

## About
Many aspiring entrepreneurs and builders spend months creating products without checking if there is actual market demand. The **AI Idea Validator** acts as an instant, intelligent co-pilot to stress-test startup concepts using AI-driven insights before writing production code.

## Key Features
* **Market Demand Analysis:** Evaluates target audience size and identifies competitors.
* **SWOT Generation:** Instantly generates Strengths, Weaknesses, Opportunities, and Threats.
* **Pivot Suggestions:** Offers constructive feedback and alternative use cases.
* **Scoring Dashboard:** Provides a clear viability score to help founders decide whether to build, tweak, or pivot.

## Tech Stack
* **Frontend:** Modern web UI framework
* **Backend / AI:** Advanced Large Language Models (LLMs) via APIs
